怎么添加新作品

  1. 用记事本或 VS Code 打开这个 works.html 文件。
  2. 找到一段 <article class="work-card"> ... </article>，整段复制。
  3. 粘贴到最后一张卡片的后面（也就是 </div> 的前面）。
  4. 把新卡片里的【】内容改成你的作品信息。
  5. 保存文件，刷新浏览器就能看到了。
小提醒：作品如果放在别的网站（比如视频链接），把 href="#" 里的 # 换成你的网址即可， 记得网址要用英文引号括起来。
